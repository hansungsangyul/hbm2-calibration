# A8 paired cross-pipeline transfer evaluation — pre-registration (2026-10-16, written before any A-side result was inspected)

Purpose. Replace the ID-vs-R comparison of VI-E by a content-matched (paired) comparison: the same 1,750 clean images degraded by model A (each configuration's own training pipeline) vs. by the reference pipeline R.

1. Content set C: download/HBM_clean image_0251..image_2000 (1,750 images). Labels: download/HBM_labels (tile-level). C is the clean origin of R's held-out images download/HBM_dirty2 0251..2000. Images 0001..0250 of R are calibration evidence and are excluded.
2. A side (a8_paired_gen.py): per configuration, theta = that configuration's training theta (D_manual: theta_manual; AB-1: theta_manual+prenorm; AB-2/AB-3: fwhm 2.0956; D_calib: fwhm 2.0956+prenorm; D_sigma_p: D_calib+sigma_post 0.016949; D_v5e: v5e theta (alpha 0.295997, in_low 0.169958, in_high 0.70, ring 0.030071, sigma_post 0.016949)+prenorm; z-score: theta_manual with per-image z-score at inference). Prenorm (a=0.501834, b=0.173320) applied to the clean image before degradation where the configuration trained that way. Epsilon seeded per image number (900000+n), identical across configurations. Border/crop as in training (320x512).
3. R side: download/HBM_dirty2 same image numbers, inference preprocessing = the configuration's declared mode (prenorm / zscore / none), rows taken from a7_labels_v2_per_image.csv (set R_heldout). The R resampling stage (imresize down and back to the same size) preserves pixel coordinates, so the same 5x20 tile grid applies to both sides.
4. Metrics per image (identical code to a7_labels_eval2.py): normal-tile pixel FPR; normal-tile false-alarm rate at tau; defect-tile recall at tau; class-correct recall at tau. Primary tau = 0.5 (fixed a priori); 0.25 and 0.75 supplementary.
5. Statistics: for each configuration and run r, Delta_i = m_R(i) - m_A(i) over the 1,750 pairs; per-run median over i; reported value = median over the 20 runs, with IQR over runs. The medians of m_A and m_R are reported separately the same way. Descriptive only; no hypothesis test. All 8 configurations x 20 runs included, no exclusions; D_v5e flagged (known double-normalization failure).
6. Primary table (VI-E): Configuration | A-degraded normal-tile FPR | R-degraded normal-tile FPR | median paired difference | A-degraded defect-tile recall | R-degraded defect-tile recall | median paired difference. ID (test_id, 500 images, theta_manual) results retained as supplementary.
7. Interpretation rule fixed in advance: differences are attributed to the degradation operator as a whole (including normalization placement), not to individual stages; no claim about measured CT images.
