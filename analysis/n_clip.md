## Q8-2. sigmoid-box 하한이 무엇이었습니까? N=5.56의 좌표

**v2 실행 당시 sigmoid-box 없었음. N = F.softplus(N_raw)**

### 버전별 N 파라미터화

| 버전 | N 공식 | 범위 | 코드 파일 |
|------|--------|------|-----------|
| **v2** (`run_phase4_v2.py`) | `N = F.softplus(N_raw)` | (0, ∞) — 하한 없음 | `run_phase4_v2.py:127` |
| **v4+** (`pipeline.py`) | `N = 50 + 950 × sigmoid(N_raw)` | [50, 1000] | `pipeline.py:174` |

### 코드 인용

v2 (`run_phase4_v2.py:127`):
```python
def get_theta_physical(pipe):
    with torch.no_grad():
        return dict(
            N=float(F.softplus(pipe.N_raw).item()),   # ← softplus, 하한 없음
            ...
        )
```

v4+ (`pipeline.py:174`):
```python
N = _N_LO + (_N_HI - _N_LO) * torch.sigmoid(self.N_raw)   # ← sigmoid-box [50, 1000]
```
여기서 `_N_LO = 50.0`, `_N_HI = 1000.0` (`pipeline.py:43-44`).

### N=5.56의 의미

`theta_real_v2.json`의 `N=5.563768`은 `F.softplus(N_raw_trained)`의 값,  
즉 **학습 완료 후 파이프라인에 실제 들어간 물리적 N** (raw 파라미터도 아니고, 역변환 전 값도 아님).

sigmoid-box 하한 50은 `run_phase4_v2.py`에 존재하지 않았음. v4 이후 추가됨.

## Q8-3. 클리핑이 검증 스크립트에만 있었습니까?

**그렇습니다. 원래 학습에는 클리핑 없었고, 검증 스크립트(이전 세션)에만 있었습니다.**

### 두 실행의 `make_pipe()` 비교

| | 원래 v2 학습 | 이전 세션 q4b/q4c 검증 |
|--|--------------|------------------------|
| 파일 | `run_phase4_v2.py` | 이전 세션 임시 스크립트 |
| pipeline.py 버전 | v2-era (softplus N) | 현재 pipeline.py (sigmoid-box) |
| N 파라미터화 | `F.softplus(N_raw)` → N ∈ (0, ∞) | `50 + 950×sigmoid(N_raw)` → N ∈ [50, 1000] |
| N=5.56 입력 시 | 5.56 그대로 사용 | `np.clip(5.56, 50.001, 999.999)` = **50.001**로 클립 |

### 결과

- `q4b_q4c_results.json`의 v2 `var_post_measured=0.0004994` → **N=50.001로 측정된 잘못된 값**
- `var_post_measured(v2, N=5.56)` 시뮬레이션 (아래 참고) → **≈ 0.0035** (7× 더 큼)
- `eq5=0.020798` → N=5.56 사용 (올바름). 따라서 ratio=0.024는 **분모(var)가 N=50, 분자(eq5)가 N=5.56 혼용**에 의한 내적 불일치

## Q8-4. N=5.56에서 가우시안 근사가 참 포아송과 얼마나 다릅니까?

### 측정 (x=0.35, n_samples=200,000)

Table 1 형식 (§III-A 동일):

| N | KS 거리 | 왜도 (참 포아송) | 왜도 (가우시안 근사) |
|---|---------|----------------|-------------------|
| **5.56** | **0.177** | **0.714** | 0.008 ≈ 0 |
| 50 | 0.065 | 0.237 | −0.010 ≈ 0 |
| 280 | 0.027 | 0.095 | −0.010 ≈ 0 |
| 300 | 0.027 | 0.092 | −0.010 ≈ 0 |

### 해석

- N=5.56에서 포아송 분포의 왜도 = **0.714** — 심각한 비대칭
- 가우시안 근사의 왜도 ≈ 0 — 대칭 분포
- KS 거리 = **0.177** — 유의미한 분포 불일치 (N=300의 0.027 대비 6.6×)
- **결론**: N≈5.56은 가우시안 근사(`y = x + √(x/N)·ε`)의 유효 범위를 크게 벗어남
  - §III-A의 "가우시안 근사가 유효한 범위(N ≳ 50)" 주장과 일치
  - §IV-B의 "비물리적 저값" 서술 유효
