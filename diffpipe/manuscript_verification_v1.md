### 53-1. §3.1 스테이지 순서 및 σ_post 위치 (pipeline.py)

**소스**: `diffpipe/src/pipeline.py`

원고: "포아송 노이즈, 가우시안 배경 노이즈, 임펄스 노이즈, PSF 블러, 비네팅, 대비 매핑, 링 아티팩트의 7단계"; σ_post는 "비네팅 후·대비 매핑 전 위치"

코드 순서 (forward 함수): S1=Poisson → S2=Gaussian → S3=S&P → S4=PSF → S5=Vignetting → [S5.5=σ_post] → S6=Contrast → S7=Ring

**판정: 일치** — 7+1 스테이지 순서 및 σ_post 삽입 위치 모두 원고 서술과 동일.

### 53-2. §3.1 링 아티팩트 수식: 극좌표+grid_sample vs 실제 구현

**원고 §3.1**: "링 아티팩트는 극좌표계에서 반경의 연속 함수로 생성한 뒤 쌍선형 보간 기반 좌표 변환(grid sample)으로 직교 좌표에 사상하며"

**코드 (`pipeline.py`, `_stage7_ring`)**: 극좌표 변환 및 `grid_sample` 미사용. 직교 좌표에서 반경 거리 맵 직접 계산 후 정현파 변조 적용:
```python
r_map = torch.sqrt((xx - cx)**2 + (yy - cy)**2)
mod = ring_strength * torch.sin(2.0 * math.pi * ring_n * r_map / rmax)
return torch.clamp(x * (1.0 + mod), 0.0, 1.0)
```

**판정: 불일치** — 원고는 "극좌표 생성 → grid_sample 역변환"을 서술하나, 코드는 직교 좌표에서 직접 sinusoidal modulation. 미분 가능성은 유지(gradcheck pass T1.S7_ring=true)되나 구현 방식이 다름. 원고 §3.1 링 서술 수정 필요.

### 53-4. §5.1 불안정 판정 서술: medfilt 적용 대상 (run_phase5_grid.py)

**원고 §5.1**: "직전 10 epoch의 검증 F1 궤적에 3점 중앙값 필터를 적용한 뒤 그 창의 변동폭(최대−최소)이 0.1을 초과"

**코드 (`run_phase5_grid.py`, `check_diverged` 함수)**:
```python
f1_arr = np.array(f1_raw, dtype=np.float32)         # 전체 누적 궤적
k = 3 if len(f1_arr) >= 3 else 1
f1_filt = medfilt(f1_arr, kernel_size=k)             # 전체 궤적에 medfilt
...
if epoch >= 20 and len(f1_filt) >= 10:
    window = f1_filt[-10:]                            # 그 후 마지막 10개 절단
    crit_3 = (max(window) - min(window)) > 0.1
```

**판정: 불일치(부분)** — 코드는 **전체 f1_raw 궤적**에 medfilt를 먼저 적용한 뒤 마지막 10개를 절단. 원고 서술 "직전 10 epoch의 궤적에 필터 적용"은 medfilt가 마지막 10개에만 적용되는 것처럼 읽힘. 결과는 최종 epoch(41ep)에서 동일하나 중간 epoch에서 두 방식의 결과가 다를 수 있음. 원고 서술을 "전체 F1 궤적에 3점 중앙값 필터를 적용한 후 마지막 10 epoch 창의 변동폭"으로 수정 필요.

### 53-5. §4.3 "§5.1과 동일한 기준" vs P4.2r v2 구현

**원고 §4.3**: "불안정 판정은 §5.1과 동일한 기준을 학습 완주 후 최종 10 epoch 창에 적용하는 사후 판정으로 통일하였다"

**판정: 일치** — 함수 동일. "사후 판정"과 "온라인 판정" 차이는 조기 종료 유무이며, 최종 epoch 기준에서는 같은 결과.

### 53-6. §4.2 ESF 절차 (`run_esf_psf.py`)

### S3. "발생률이 높은 저노이즈 셀들의 수렴 run은 F1 0.93 이상"

**원천**: phase5_runs_level.csv, 수렴 run 필터 후 셀별 F1 집계

저노이즈(σ_g≤0.041) 중 발생률 ≥3/5 셀의 수렴 run 최대 F1:
- sg0(σ=0.01025),fw2(f=2.5), div=3/5: max F1=0.955 ✓
- sg1(σ=0.0205),fw0(f=0), div=3/5: max F1=0.963 ✓
- sg1,fw4(f=5.0), div=4/5: max F1=**0.909** ✗
- sg2(σ=0.041),fw4(f=5.0), div=4/5: max F1=**0.849** ✗

소결: 저노이즈·소블러(f≤2.5) 고발생률 셀의 수렴 run은 F1 0.93 이상을 달성하는 경향이 있으나, 저노이즈·고블러(f≥5.0) 고발생률 셀은 F1 0.93 미만.

**판정: 불일치(부분)** — 원고 서술 "발생률이 높은 저노이즈 셀들의 수렴 run은 F1 0.93 이상"은 고블러 저노이즈 셀(sg1_fw4 max=0.909, sg2_fw4 max=0.849)에서 반례가 존재. 주변 맥락(준청정 영상의 "적정 블러 계곡" 논의)에서 f≤2.5 셀을 염두에 두었다면 근사 성립하지만, 서술 범위가 모호. §5.2 수정 시 f 조건 명기 권고.

### S4. "능선 근사식 Var_post ≈ (x̄/N + σ_g²)·κ(f), κ∝1/f²"

**검토**: 파이프라인 순서는 S3(S&P) → S4(PSF). S&P(p=0.001)의 임펄스가 PSF로 일부 평활화되므로, 관측 분산에는 Poisson+Gaussian+일부_평활_S&P 성분이 포함됨. p=0.001이면 S&P 기여는 극히 미소(~0.001×pixel variance)하여 Var_post 근사에서 무시 가능. κ(f)∝1/f²는 Gaussian PSF의 분산 감쇠 형태로 타당.

**판정: 일치(근사)** — 파이프라인 순서 하에서 근사가 성립하는 조건(S&P 기여 무시 가능)이 p=0.001로 충족됨. 단, 수식이 시그마 기반 유효 블러 범위(f≥0.5 정도) 내에서만 유효하며 f=0 또는 극소 f에서는 κ 해석 주의 필요 — 이 조건은 원고 §3.3에 명시되지 않아 footnote 권고.

### S5. "41 epoch(파일럿의 성능 정체 시점 + 여유분으로 결정)"

**검토**: phase5/run_phase5_grid.py는 현재 "신 θ + prenorm=True" 구성. HANDOFF v6.13 §B-3에서 확인된 대로 phase5 베이스 구성이 전작(구θ) 파일럿과 동일하지 않음. 파일럿 성능 정체 데이터 파일이 §3~5 원천 범위 내에서 미발견.

**판정: 근거 없음(부분)** — 41 epoch 자체(epochs=41 코드 확인 ✓)는 일치하나, "파일럿의 성능 정체 시점"이라는 결정 근거가 현 실험 원천 데이터에서 확인 불가. 원고에 "파일럿은 현 베이스 구성과 상이"라는 캐비앗 추가 권고.

### [불일치 1] §3.1 링 아티팩트 구현 서술

**현재 원고 문장**:
> "링 아티팩트는 극좌표계에서 반경의 연속 함수로 생성한 뒤 쌍선형 보간 기반 좌표 변환(grid sample)으로 직교 좌표에 사상하며, 보간이 미분 가능하므로 진폭·주파수 파라미터에 기울기가 전달된다."

**실제 코드** (`src/pipeline.py:241–256`, `_stage7_ring`):
```python
def _stage7_ring(self, x: torch.Tensor) -> torch.Tensor:
    """Concentric ring artifact via sinusoidal radial modulation."""
    ring_strength = F.softplus(self.ring_strength_raw)
    ring_n        = F.softplus(self.ring_n_raw)
    H, W = x.shape[-2], x.shape[-1]
    cy, cx = H / 2.0, W / 2.0
    yy, xx = torch.meshgrid(torch.arange(H, ...), torch.arange(W, ...), indexing='ij')
    r_map = torch.sqrt((xx - cx)**2 + (yy - cy)**2)
    rmax  = r_map.max() + 1e-8
    mod   = ring_strength * torch.sin(2.0 * math.pi * ring_n * r_map / rmax)
    return torch.clamp(x * (1.0 + mod), 0.0, 1.0)
```

**수정 제안**:
> "링 아티팩트는 직교 좌표에서 픽셀 중심까지의 반경 거리 $r$을 직접 계산하여 $A \cdot \sin(2\pi n \cdot r/r_{max})$의 정현파 강도 변조를 적용한다. $A$, $n$이 미분 가능 파라미터이므로 진폭·주파수에 기울기가 전달된다."

**참고**: `grid_sample` 미사용. 미분 가능성은 직교 좌표 수식으로도 성립하며 gradcheck T1.S7_ring=PASS 확인됨.
