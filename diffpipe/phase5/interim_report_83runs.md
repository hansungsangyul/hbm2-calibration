## 위상도 신호 (조기 분석)

### 발산율 행렬 (완료 셀만, fwhm×σ_g)

```
fwhm↓ / σ_g→     0.01025  0.02050  0.04100
  0.000 (G2)       2/5      3/5      0/5
  0.625             1/5      2/5      2/5
  1.250             0/5      0/5      1/5
  2.500             3/5      2/5      1/5
  5.000             2/5      4/5      3/3(진행중)
 10.000             5/5      5/5      (미완)
```

**신호**:
- **안정 영역**: fwhm ≤ 1.25 → 대부분 발산율 0~1/5
- **전이 영역**: fwhm ≈ 2.5 → 발산율 1~3/5 (σ_g 의존성 뚜렷)
- **불안정 영역**: fwhm ≥ 5.0 → 발산율 2/5~5/5
- **σ_g 효과**: fwhm=2.5에서 σ_g 증가(0.01→0.041)에 따라 발산율 감소(3→2→1) — 노이즈 정규화 효과 가능성

### GRV (기울기 상대분산) 초기 5 epoch 평균

- fwhm=0~1.25: GRV 31~40 → 학습 안정
- fwhm=2.5: GRV 64~70 → 큰 폭 상승
- fwhm=5.0: GRV 81~84 → 불안정
- fwhm=10.0: GRV 100~108 → 최고

GRV와 발산율 간 **강한 양의 상관** 확인. GRV > ~60 이 발산 위험 지표로 기능하는 양상.
