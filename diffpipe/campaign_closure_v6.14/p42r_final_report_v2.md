### 등가성 검정 (TOST δ=0.004)

사전 등록 가설:
- H0: |μ_manual − μ_calib| ≥ δ (비동등)
- H1: |μ_manual − μ_calib| < δ (동등)

| 통계량 | 값 |
|---|---|
| diff (manual − calib) | **+0.0105** |
| Welch SE | **0.0211** (= √(s_c²/20 + s_m²/20) = √(0.049²/20 + 0.081²/20)) |
| 95% CI for diff | [−0.0323, **+0.0533**] |
| df (Welch) | 38 |
| t₁ (H0: diff ≤ −δ): t=(diff+δ)/SE | 0.687, p=0.2482 |
| t₂ (H0: diff ≥ +δ): t=(diff−δ)/SE | 0.308, p=0.6203 |
| **p_TOST = max(p₁, p₂)** | **0.6203** |
| 판정 | **동등성 미확인** (p > 0.05) |

95% CI 상한 +0.053이 δ=0.004를 크게 초과. 점추정치 +0.011도 δ 방향 초과.

## crit 3 개념 정리

**crit 3는 학습 안정성 사건이며 최종 성능 지표가 아니다.**

- 기준: 전체 f1_raw(41ep)에 medfilt-3 적용 → f1_filt[-10:] (epoch 32~41) max − min > 0.1
- 목적: 학습이 수렴하지 못하고 진동하는 상태를 포착
- 한계: 창 내 중간 dip(일시 하락)만으로도 발동. 최종값이 높아도 중간 진동이 기준을 만족하면 발산 판정

대표 사례:
- manual run10 (seed 760018): final_f1=**0.965**이나 발산 판정 (창 spread=0.103)
- calib run8 (seed 750016): final_f1=**0.946**이나 발산 판정 (창 spread=0.117)

발산 판정 = 안정성 사건. 이 run들을 "실패한 학습"으로 해석하는 것은 부적절하다. 논문 Table 3에서 발산율을 "학습 실패율"이 아닌 "F1 oscillation 발생률"로 기재할 것.

## 각주

### 각주 F1 — medfilt-3 경계 처리 (scipy.signal.medfilt)

`scipy.signal.medfilt(arr, kernel_size=3)`는 경계에서 **zero-padding**을 적용한다. 즉, 길이 n 배열의 마지막 원소 필터값은 `median([arr[-2], arr[-1], 0])`이 된다.

이는 v6.1 스펙의 "경계 원값 유지" 기술과 상이한 동작이다 (v6.1 스펙의 오기로 기록).

경계 zero-padding이 crit 3 발동에 영향을 미친 한계 사례 — **manual run10 (seed 760018)**:

원시 epoch 32~41 F1 (f1_raw[-10:]):
```
0.941  0.954  0.957  0.948  0.784  0.918  0.954  0.963  0.861  0.965
```

medfilt-3 (zero-padding) 적용 후:
```
position  raw      filtered        계산
0 (ep32): 0.941  → 0.941  median([0, 0.941, 0.954])
1 (ep33): 0.954  → 0.954  median([0.941, 0.954, 0.957])
2 (ep34): 0.957  → 0.954  median([0.954, 0.957, 0.948])
3 (ep35): 0.948  → 0.948  median([0.957, 0.948, 0.784])
4 (ep36): 0.784  → 0.918  median([0.948, 0.784, 0.918])
5 (ep37): 0.918  → 0.918  median([0.784, 0.918, 0.954])
6 (ep38): 0.954  → 0.954  median([0.918, 0.954, 0.963])
7 (ep39): 0.963  → 0.954  median([0.954, 0.963, 0.861])
8 (ep40): 0.861  → 0.963  median([0.963, 0.861, 0.965])
9 (ep41): 0.965  → 0.861  median([0.861, 0.965, 0])   ← zero-padding
```

필터 후 창: [0.941, 0.954, 0.954, 0.948, 0.918, 0.918, 0.954, 0.954, 0.963, **0.861**]
max=0.963, min=0.861, **range=0.102** → crit 3 발동 (임계 0.1 초과)

zero-padding 없이 "reflect" 경계를 적용했다면:
- 마지막 필터값: median([0.861, 0.965, 0.965]) = 0.965
- range ≈ 0.022 → crit 3 미발동

이 1건은 zero-padding으로 인한 경계 아티팩트가 발산 판정을 야기한 사례다. 그러나 전 150 Phase 5 runs와 전 40 P4.2r v2 runs에 동일하게 적용됐으므로, 처리 일관성은 유지된다. 기준 변경(면제 조건 추가)은 사전 등록 위반이므로 도입하지 않음 (v6.13 §A Q4 기각 반영).
