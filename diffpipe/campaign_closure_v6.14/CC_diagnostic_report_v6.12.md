## §1 — 조기 종료 판별

### §1.1 코드 사실 확인

**run_p42r.py** (P4.2r 학습 루프):
```python
# L294-298
div, reason, f1_filt_list = check_diverged(train_loss_list, f1_raw_list, epoch, args.epochs)
if div:
    diverged = True; divergence_reason = reason
    print(f'\n[DIVERGED] criterion {reason} at epoch {epoch}')
    break   # ← (a) 조기 종료 구현
```

**run_phase5_grid.py** (Phase 5 학습 루프):
```python
# L415-421
div, reason, f1_filt_list = check_diverged(train_losses, f1_raw, epoch, cfg_ep)
if div:
    diverged = True; divergence_reason = reason
    print(f"\n[DIVERGED] criterion {reason} at epoch {epoch}")
    break   # ← (a) 조기 종료 구현 (Phase 5도 동일)
```

**결론**: 두 스크립트가 **동일한 조기 종료 구현**을 공유한다. HANDOFF §1에서 "(b) 사후 판정(Phase 5 방식)"이 대안으로 상정됐으나, 실제로는 Phase 5도 `break`를 사용한다. 따라서 P4.2r manual 100% 발산의 원인을 "Phase 5와의 구현 차이"로 돌릴 수 없다.

두 구현의 구조적 차이는 `break` 유무가 아니라 **batch 크기**:
- Phase 5 그리드: batch=16 → steps/ep ≈ 63 → epoch 20 도달 시 누적 ≈1,260 steps
- P4.2r: batch=32 → steps/ep ≈ 32 → epoch 20 도달 시 누적 ≈640 steps

P4.2r manual은 epoch 20 시점에 weight update 수가 절반이므로, 수렴 안정화 전의 F1 진동이 더 크게 나타나 crit 3가 발동됐을 가능성이 있다.

| 가설 | 판정 | 근거 |
|---|---|---|
| H1: batch 소 → 고분산 gradient → 학습 불안정 | **기여 요인 (주범 미결)** | 비단조요동 20/20이 H1 방향과 일치. 단 §4-A로 조기 종료 효과 분리 후 재평가 |

### §7.4 등가성 검정 (TOST δ=0.004)

**가설**:
- H0: |μ_manual − μ_calib| ≥ δ (비동등)
- H1: |μ_manual − μ_calib| < δ (동등)

**결과**:

| 통계량 | 값 |
|---|---|
| diff (manual − calib) | **+0.0105** |
| 95% CI for diff | [−0.0323, **+0.0533**] |
| pooled SE | 0.01529 |
| df | 38 |
| t1 (하한 검정, H0: diff ≤ −δ) | +0.687, p=0.2482 |
| t2 (상한 검정, H0: diff ≥ +δ) | +0.308, p=0.6203 |
| **p_TOST = max(p1, p2)** | **0.6203** |
| 판정 | **동등성 미확인** (p_TOST > 0.05) |

95% CI 상한이 +0.053으로 δ=0.004를 크게 초과. 점추정치 자체(+0.011)도 δ를 넘어 방향성이 있음. 동등성 주장 불가.

### §7.9 §4-A 최종 판정문

**Q1. 조기 종료가 v1 manual 100% 발산의 주원인인가?**
→ **예.** 41ep 완주 + 사후 판정 전환으로 manual 발산율이 100% → 20%로 급감. epoch 20 시점 일시적 F1 진동을 crit 3가 조기 발동한 것이 주요 원인임을 확인.

**Q2. calib과 manual은 동등한가 (TOST δ=0.004)?**
→ **아니오.** p_TOST=0.62 (α=0.05 미달). 95% CI [-0.032, +0.053]가 ±δ 경계를 크게 초과. 동등성 주장 불가.

**Q3. 어느 조건이 더 우수한가?**
→ **단일 답 없음 — 테스트셋 의존성 존재.**
- val F1·TEST_ID: manual 우세 (MWU p=0.0013, Δ≈+0.05)
- TEST_OOD: calib 우세 (+0.191)
- TEST_CAL: calib 우세 (+0.331)
- manual의 in-distribution 우세가 OOD·CAL에서 역전됨 → **prenorm=False + fwhm=2.5 조합이 분포 이동에 취약**함을 시사

**Q4. crit 3 (사후 판정) 기준 자체에 문제가 있는가?**
→ **부분 있음.** calib run4(final=0.925)·run8(0.946)·run10(0.923), manual run10(0.965)은 최종 F1이 높음에도 중간 dip으로 crit 3 발동. crit 3는 학습 안정성 지표이지 최종 성능 지표가 아님 — 발산 판정이 최종값과 무관하게 이루어짐. 향후 발산 판정 기준에 "최종값 예외 조건(final_f1 ≥ 0.92 시 crit 3 면제)" 추가를 검토할 수 있으나, 사전 등록된 기준 변경이므로 별도 결정 필요.

**Q5. 다음 단계는?**
→ Phase 5 그리드 결과(A1~A3) 재해석 시, prenorm 적용(§2 확인)과 manual θ의 OOD 취약성(본 §7.6)을 함께 고려해야 함. §4-A 결과로 P4.2r 수준 재실행 결론: **calib을 기준값으로 사용하되 manual과의 동등성 주장은 철회.**
