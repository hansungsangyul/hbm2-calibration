## §3 A1 미리보기 — exploratory (interim, n=83)
### ⚠ 사전 등록 본 분석 지위 불변 (150 runs 완료 후 별도 수행)

**분석 대상**: 83 runs × [초기 5 epoch GRV 평균, 발산 여부]

### 점이연 상관

| 항목 | 값 |
|---|---|
| n | 83 |
| 발산 | 36 / 비발산 47 |
| r_pb | **0.4544** |
| p-value | **1.59e-05** |
| GRV mean (발산) | 70.84 ± 30.24 |
| GRV mean (비발산) | 45.87 ± 18.39 |

r_pb = 0.45: 중등도 양의 상관, 고도 유의 (p < 0.0001) — 초기 GRV가 높을수록 발산 경향 유의미하게 증가.

### GRV > 60 임계 혼동 행렬

|  | 실제 발산 | 실제 비발산 |
|---|---|---|
| **GRV > 60 (예측 발산)** | TP = 24 | FP = 11 |
| **GRV ≤ 60 (예측 비발산)** | FN = 12 | TN = 36 |

| 지표 | 값 |
|---|---|
| Sensitivity | **0.667** |
| Specificity | **0.766** |
| PPV | 0.686 |
| NPV | 0.750 |

**해석 (탐색적)**:
- GRV > 60 임계: 발산 예측 Sensitivity 67%, Specificity 77% — 부분 유용, 단일 지표 불완전
- 임계 60은 사전 시각 판단 기반 (데이터 기반 선택 아님). 본 분석에서 ROC 최적 임계 재산출 예정.
- 미완 67 runs 추가 시 (특히 sg3/sg4 고σ_g 행) r_pb 및 임계 재보정 필요 — 현재 sg2까지만 있어 σ_g 분포 치우침.
- FN=12 (발산했으나 GRV≤60): sg0_fw4(2)/sg1_fw3(2)/sg2_fw1(1~2) 등 — 중등 fwhm + 저σ_g 조합에서 초기 GRV가 낮아도 발산 가능.
