## 2. GRV 산식 감사 (v7.8 §3 의무 조항)

**UNet (Phase5) 산식** (run_phase5_grid.py:252-263):
```
g = cat(모든 파라미터 기울기 flatten)
GRV = Var(g) / E[|g|]²        ← 요소별 분산/절댓값평균²
```

**DeepLab (Exp6 v7) 산식** (run_exp6_arch.py:219-240):
```
grad_norms = [‖∇‖₂ per batch, 5 batches]
GRV = std(grad_norms) / mean(grad_norms)   ← 배치별 노름의 변동계수(CV)
```

**감사 결론**: **산식 상이** — 동일 Var/Mean² 산식이 아님.  
- UNet 범위: 30~115 / DeepLab(v7) 범위: 0.08~0.11 → 스케일 괴리 원인 확정  
- 재실행(v8)에서 UNet과 동일 산식(Var(g)/E[|g|]²) 적용 필요
