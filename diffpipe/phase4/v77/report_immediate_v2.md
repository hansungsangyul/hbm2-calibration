## 실험 1 — 추론 시 정규화 재평가 (M4) [정정판]

**판정표 (HANDOFF v7.7 §1)**: 배치 정직 비교 기준
- gap > −0.01  → **ID_RESOLVED**
- −0.03 < gap ≤ −0.01 → **ID_PARTIAL**
- gap ≤ −0.03 → **TRADEOFF_REAL**

| 정규화 모드 | calib ID F1 | 비교 대상 | ID F1 | gap | 판정 |
|------------|-------------|-----------|-------|-----|------|
| orig     | 0.8757 | manual+orig | 0.9269 | −0.0512 | **TRADEOFF_REAL** |
| prenorm  | **0.9120** | manual+orig (배치 정직) | **0.9269** | **−0.0149** | **ID_PARTIAL** |
| zscore   | 0.2001 | — | — | — | **공허** (작동 모델 아님, F1≈0.2) |

**정정 판정**: prenorm 모드 = **ID_PARTIAL**  
  → "추론 시 prenorm 정합으로 ID 격차가 −0.051→−0.015로 완화. 완전 해소는 아님."

**실험 1 OOD 보완**: §1 (v7.8 지시 70) 실행 중 → 판정 PENDING  
  원고 처리는 OOD 보완 결과 수신 후 결정.

## 실험 2 — 실영상 무결함 위양성률 (M5) [오류 발견, 재실행 예정]

**전처리 감사 결과** (v7.8 §2 의무 조항):

| 항목 | 코드 위치 | 현황 | 문제 |
|------|-----------|------|------|
| dtype / 강도 범위 | run_exp2_real_fpr.py:74 `astype(np.float32)/255.0` | uint8→float32 [0,1] ✓ | 없음 |
| 해상도 정합 | run_exp2_real_fpr.py:76 `copyMakeBorder(3,3,0,0)[:, 4:516]` | 학습 동일 ✓ | 없음 |
| 이진화 | run_exp2_real_fpr.py:98 `pred_logits.argmax(dim=1)` | argmax ✓ | 없음 |
| **조건별 전처리** | run_exp2_real_fpr.py:71-79 `load_dirty2_tensor` | **모든 모델 동일 원본 [0,1]** | **calib 모델에 prenorm 적용 누락** |

**핵심 결함**: `load_dirty2_tensor`(L71-79)는 조건 무관하게 원본 이미지를 그대로 반환. calib 모델은 prenorm(A=0.501834, B=0.173320)으로 학습됐으므로 추론 시에도 prenorm 필요. 적용 누락 → 학습-추론 분포 불일치 → pixel_fpr=0.9812는 이 결함의 지문.

**v7 EQUIVALENT 판정 철회** — §1 결론(prenorm 추론 정합)과 일관된 전처리 수정 후 재실행(§2) 필요.  
오버레이 PNG 및 수정 후 결과는 §2 보고서에서 제출.
