## MC5 불확실성 CI

**실행일**: 자동 생성 (HANDOFF v7.6 §3.2)
**목적**: f 실측 2.057의 이미지 층화 부트스트랩 CI → FWHM_FROZEN 전파

### 데이터

| 이미지 | median FWHM | n_valid_edges | sufficient |
|--------|-------------|---------------|------------|
| dirty2_img00 | 2.0569 | 149 | True |
| dirty2_img01 | 1.2030 | 19 | False |
| dirty2_img02 | nan | 0 | False |
| dirty2_img03 | 2.4519 | 475 | True |
| dirty2_img04 | 1.9050 | 169 | True |

- **유효 이미지** (sufficient=True, R²≥0.95): 3매
- **per-image medians**: ['2.0569', '2.4519', '1.9050']
- **관측 grand median f**: 2.0569

### 자기 검증 교정

- Applied FWHM = 2.5 → 측정 strict median = 2.4537
- 교정 비율 = 2.5/2.4537 = 1.018883
- **FWHM_FROZEN** = 2.0569 × 1.018883 = **2.0957**

### 부트스트랩 CI (N = 100,000)

이미지 층화 리샘플: n_img = 3매에서 복원 추출, 표본 중앙값 계산.

| 지표 | 값 |
|------|---|
| Boot mean (f_raw) | 2.1204 |
| Boot std  (f_raw) | 0.2064 |
| 95% CI (f_raw, percentile) | [1.9050, 2.4519] |
| **95% CI (FWHM_FROZEN)** | **[1.9410, 2.4982]** |
| CI width (FWHM_FROZEN) | 0.5573 |

### 해석 (사전 판정 기준)

- FWHM_FROZEN = 2.0957 ∈ [1.9410, 2.4982]
- n=3 이미지로 CI가 넓음: ±0.2786 (반폭)
- Phase 5 f 그리드 (0, 0.625, 1.25, 2.5, 5.0, 10.0) 중 FWHM_FROZEN은 2.5 셀에 근접
  → ESF 앵커 위치 불확실성이 셀 경계를 넘지 않음 (2.5 셀 내 유지)

### 자기 검증 편향 f-의존성

f=2.5 단일 점만 측정됨 → f-의존성 정량화 불가.
교정 비율 2.5/2.4537 = 1.018883을 단일 보정 인자로 적용.
