## 2. 핵심 발견

### 발견 1: prenorm이 OOD 강건성의 주 동력

prenorm=True만 추가한 AB-1이 D_calib(0.787)를 **초과**(0.816):

```
D_manual  → AB-1  : +0.2195  (+36.8%p)  prenorm=True, fwhm 그대로
D_manual  → D_calib: +0.1910             둘 다 교정
```

prenorm 단독으로 전체 gap(0.191)의 **114.9%** 설명 → prenorm이 충분 조건.

### 발견 2: ESF fwhm 교정은 prenorm 없이 오히려 역효과

fwhm만 교정한 AB-2가 D_manual보다 **낮음**(0.487 vs 0.596, −0.109):

```
D_manual  → AB-2  : −0.1090  (−18.3%p)  fwhm 교정, prenorm 없음
```

교정된 fwhm=2.0956이 prenorm 없는 상태에서 오히려 분포 불일치를 악화.

### 발견 3: prenorm 있을 때 fwhm 교정 효과 미약 (약간 음)

```
AB-1 (prenorm=T, fwhm=2.5) = 0.8155
D_calib (prenorm=T, fwhm=2.0956) = 0.787
차이: −0.0285  (미약한 감소, 신뢰구간 내 겹침 가능)
```

prenorm이 있을 때 fwhm 교정의 추가 이득은 없거나 소폭 음적.

### 발견 4: AB-2·AB-3 완전 재현 (p=0.797)

동일 조건 다른 시드(AB-2 vs AB-3)의 Mann-Whitney U: **p=0.797** → 재현성 완전 확인.  
이후 모든 분석에서 AB-2·AB-3 병합 가능 (n=40).

## 6. 해석

### prenorm의 역할
prenorm(a=0.501834, b=0.173320)은 합성 훈련 이미지와 실제 테스트 이미지 간 **강도 분포 정합**을 수행.  
이 전처리가 없으면 검출기가 합성 분포에 과적합 → OOD에서 급격한 성능 저하.

### ESF fwhm 교정의 역설
fwhm=2.5(수동) vs fwhm=2.0956(ESF 교정)의 차이는 약 0.04 픽셀.  
prenorm 없이 이 미세한 차이가 악화되는 이유:
- 훈련 이미지의 PSF가 실제보다 약간 날카롭게 생성됨
- prenorm 없는 상태에서 이미지 강도 분포가 이미 어긋나 있어, PSF 정확도 이득이 분포 불일치 손실에 압도됨

### 결론
**분포 정합(prenorm)이 OOD 강건성의 필요충분 조건.**  
ESF fwhm 교정은 prenorm과 결합 시 중립 또는 미약한 음적 효과 (−0.029, CI 내 겹침).
