## 해석 (HANDOFF v7.6 §2 기준)

### 능선 잔존 패턴
1. **N=50 (sigmoid_box 최솟값)**: 최적화기가 N_raw → −∞ 방향으로 이동 → 극한적 비물리값. v1(N≈279)과 전혀 다른 비물리 지점.
2. **σ_g=0.072 (Tier1 상한 1.75배)**: v1(0.192)보다 덜 극단적이나 여전히 비물리.
3. **fwhm=1.914 (ESF 2.057 미만)**: v1(1.753)보다 덜 극단적, 하지만 ESF 실측에서 벗어남.
4. **σ_post ≈ 0.011 (초기값 0.01 유지)**: 능선 탈출에 미활용.

### 능선 이동 원인
- σ_post가 잡음 통계 일부를 흡수 → σ_g의 잡음 보상 부담 경감 (0.192→0.072)
- N 부담이 극단으로 이동 (279→50): σ_post 추가 시 Poisson 항의 역할이 재분배되어 N이 최솟값으로 수렴
- **결론**: 능선의 위치가 이동했으나 능선 자체는 소멸되지 않음 (identifiability 문제 유지)

### sigma_post 역할
- sigma_post=0.011 ≈ 초기값 → 학습 과정에서 거의 최적화되지 않음
- 이는 기존 비물리 능선이 (N, σ_g, fwhm)으로 통계 매칭을 충분히 달성하기 때문
- sigma_post는 능선 구조를 파괴하지 못함 → MC2 반론 격파 근거
