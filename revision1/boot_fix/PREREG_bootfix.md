# Bootstrap correction for between-configuration contrasts (pre-specified 2026-09-27, committed before running)
Issue: run_a3_bootstrap.py reused the same resampled run indices for both configurations (imposes run pairing; configurations use different training seeds, so runs are not paired). run_a4_bootstrap.py resampled images independently per configuration (images are shared test images, so a contrast should share image indices).
Correct scheme for every contrast X - Y on a test set: in each replicate, draw run indices independently for X and for Y (with replacement, n_runs each), draw ONE image index vector (with replacement, 500) shared by X and Y; statistic = mean over resampled runs of dataset-level macro F1 (four-class and defect-only). B = 4000, seed 20260927. 95% percentile interval.
Contrasts: D_calib - D_manual (TEST_ID, TEST_OOD, TEST_CAL); AB-4 - D_calib and AB-4 - AB-1 (TEST_ID, TEST_OOD, TEST_CAL). Point estimates are unchanged; only intervals are replaced in the manuscript.
