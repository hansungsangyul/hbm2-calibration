# A13 — Label-assisted sensitivity of the calibration statistics and of the fixed-N estimate to the pixel support: pre-registration

Registered 2026-10-17 after the published v5c result (f = 1.356) and the composition of R (72.15% defect tiles; Section III-B) were known, but before any A13 result was inspected. Addresses Reviewer 3 and the adversarial pre-submission review (item B-04): the calibration statistics of Section III-C were computed on reference images whose tiles contain procedurally inserted defects. In v5c the synthetic side degrades the clean counterparts of the same 50 images, so the defect content is present on both sides; the question is whether restricting the objective to normal-labelled support changes the statistics or the reached estimate nonetheless. This is a label-assisted sensitivity analysis and an explicit exception to the label-free character of the original calibration; it does not replace any published result. Design reviewed by Codex (thread 01a14805, 2026-10-17); its requested changes are incorporated.

## 1. Data
Reference images R 0001–0050 (download/HBM_dirty2) and their clean counterparts (download/HBM_clean 0001–0050) with prenorm a = 0.501834, b = 0.173320 applied to the clean inputs, exactly as in v5c. Tile labels download/HBM_labels (5×20 grid; tile class by majority of the label mask within the tile).

## 2. Support conditions (frozen before optimisation; a13_support.py)
- U: the original support (all pixels; the archived flat-selection rules, bin edges, Hann window and Gaussian residual operator of CalibrationLoss).
- N: U intersected with the normal-labelled tiles of each image (variance–mean patches must lie wholly inside normal-labelled tiles; pixel-based statistics use pixels inside normal-labelled tiles).
- C: label-unrestricted support control: within each image and tile row, the same number of tiles as labelled normal in that row, chosen by a fixed random permutation (numpy RandomState(820000 + image number)) independent of image intensities, predictions and defect identities; the same realisation is used throughout optimisation and across seeds.
Identical per-image support is applied to the reference image i and to the synthetic image generated from its clean counterpart i (img_idx = step mod 50 in the v5c loop), and is held fixed during optimisation. The original reference-derived flat-selection rules (50th-percentile patch gradient for the variance–mean term; 30th-percentile pixel gradient for the spectral term), bin edges, residual operator and preprocessing are frozen from the full images before the label restriction is applied; the variance–mean bins keep the original assignment, and the reference curve for each bin averages the supported patches over the images in which the patch position is supported. Empty bins and radial bins without supported pixels are excluded identically on both sides (common-support rule), never zero-filled or dropped differently between arms.

Spectral term: the Gaussian residual field is computed before masking; the effective window is W_i = H·M_i (H the original Hann window × flat mask, M_i the support), and the power spectrum is normalised by sum(W_i²) with the common frequency bins and a fixed floor. For U this normalisation cancels in the log-ratio and reproduces the archived objective (checked numerically before the run); for N and C it removes the dependence on the support size. The masked spectrum is a masked spectral objective, not an estimate of an uncontaminated physical NPS.

## 3. Calibration protocol
v5c unchanged except for the support: Tier 1 frozen (N = 300, σ_g = 0.0408, p = 0.001), out_low/out_high frozen (0.10/0.90), σ_post = 0, Tier 2 free (fwhm, α, in_low, in_high, ring_strength, ring_n) initialised at θ_manual (fwhm 2.5), Adam lr 0.01, 2000 steps, batch 8 noise realisations per step, image order step mod 50, in_low/in_high projected to [0, 0.3]/[0.7, 1.0]. Exactly three seeds {970000, 971000, 972000}; each seed is run under U, N and C with the same initialisation, bounds, optimiser, parameterisation, image order and random fields. The primary comparison is the seed-paired difference between the contemporaneous U, N and C runs; the archived v5c value f = 1.356 provides a reproduction check of U, not the sole control. Reached endpoints are reported as reached endpoints; "converged" is used only if the last 200 steps of a run vary by less than 0.01 in fwhm.

## 4. Outputs
For each arm: the reference statistic vectors (variance–mean log curve and valid bins, normalised spectrum, radial profile, histogram), the per-image support pixel and patch counts and window energies; the four loss components at θ_manual and at the published v5c θ with common model-A random draws (seed 123, 4 draws per image, all 50 images); per-run optimisation traces (per-step loss components and parameters) and reached Tier-2 parameters. Summary: fwhm per arm and seed; seed-paired differences N − U, C − U, N − C; the same for the other Tier-2 parameters.

## 5. Interpretation rules (fixed in advance)
Any change is described as sensitivity to the support selection and objective construction used here, with its magnitude reported relative to the contemporaneous U and C controls: if N differs from U and C differs from U in the same direction by a similar amount, the change is not attributed mainly to the exclusion of defect-labelled tiles; if N differs from C as well, the result indicates sensitivity to normal-labelled support selection, which is not causal evidence that the defect content biased the published estimate. The published alternative-weighting means (W1–W4: 1.322, 0.970, 1.384, 1.388) are descriptive context only, not an acceptance band or an uncertainty interval. Normal-labelled regions may still contain effects propagated from nearby defects by blur, compression and resampling. No claim of bias removal, physical blur recovery or explanation of the ESF gap; no downstream configuration is changed; the original calibration's label-free statement is retained with A13 identified as the label-assisted exception. Results enter Section III-C/IV (one paragraph), Limitation 4 or 5 as appropriate, the supplementary material (full tables) and the response to Reviewer 3.
